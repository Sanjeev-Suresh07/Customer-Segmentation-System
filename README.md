# Data-Driven Customer Segmentation and Behavior Analysis for Personalized Marketing

## Project Overview
This project analyzes customer behavior using data science techniques to identify meaningful customer segments and provide personalized marketing strategies. By applying clustering algorithms, the system groups customers based on their purchasing patterns, helping businesses understand their customers better and make data-driven marketing decisions.

## Objectives
- Analyze customer behavior and purchasing patterns.
- Perform Exploratory Data Analysis (EDA).
- Segment customers using clustering techniques.
- Evaluate clustering performance.
- Generate personalized marketing insights.
- Develop an interactive dashboard for visualization.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Git & GitHub
